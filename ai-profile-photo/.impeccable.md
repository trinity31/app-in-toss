## Design Context

### Users
- **주요 타겟**: 40~50대 여성
- **사용 맥락**: 토스 앱 내부 WebView에서 AI 프로필 사진 생성
- **목표**: SNS, 메신저, 비즈니스용 고퀄리티 프로필 사진을 간편하게 만들기
- **감정 목표**: 재미(Fun)와 놀라움(Wow) — "이게 나야?" 하는 감탄

### Brand Personality
- **3단어**: 재미있는 / 전문적인 / 놀라운
- **톤**: 친근하지만 결과물은 프로급, 과정은 즐겁고 결과는 감탄스러운
- **피해야 할 것**: 유치하거나 싸 보이는 느낌, 지나치게 테크 중심적인 UI

### Aesthetic Direction
- **비주얼 톤**: 따뜻하고 세련된 — 4050 여성이 신뢰하면서도 즐거워할 수 있는 방향
- **색상**: 현재 핑크(#db5c7f) 기반, 따뜻한 톤 유지
- **테마**: 라이트 모드 (토스 앱 내부)
- **모바일 전용**: 토스 인앱 WebView, 터치 인터랙션 중심

### Design Principles
1. **결과가 말하게 하라** — 생성된 사진의 퀄리티가 최고의 마케팅. 결과물을 최대한 돋보이게 하는 UI
2. **과정을 즐겁게** — 기다리는 시간도 재미의 일부. 로딩, 트랜지션 모두 경험의 일부로 설계
3. **신뢰를 먼저** — 4050 사용자가 낯설지 않도록. 명확한 안내, 큰 텍스트, 직관적 흐름
4. **공유가 자연스럽게** — 결과물이 좋으면 자랑하고 싶다. 공유/저장 플로우를 매끄럽게
5. **가치를 체감한 후 결제** — 무료 체험 → 퀄리티 확인 → 자연스러운 유료 전환
