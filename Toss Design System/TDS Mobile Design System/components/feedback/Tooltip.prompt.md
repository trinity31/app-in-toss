Use `Tooltip` to point at one element and explain it. TDS tooltips are white-on-white with a soft floating shadow, not dark.

```jsx
<Tooltip placement="bottom">여기를 눌러 계좌를 추가해요</Tooltip>
```

Text is bold (700) at 13 / 15 / 17px, capped at 247px wide. The tail is a single 38.4×11.4 concave-shouldered path — reuse it, do not draw a triangle.
