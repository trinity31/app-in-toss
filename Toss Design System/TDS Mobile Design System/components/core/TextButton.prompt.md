Use `TextButton` for secondary/tertiary actions that sit inside content — "더보기", "전체보기", header accessories.

```jsx
<TextButton appearance="arrow">자세히 보기</TextButton>
```

Sizes S 13px / M 17px / L 20px, weight 510. `appearance="arrow"` appends the 24px chevron glyph used throughout TDS; `underline` is reserved for legal/consent copy.
