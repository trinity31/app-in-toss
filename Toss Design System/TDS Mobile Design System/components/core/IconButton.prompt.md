Use `IconButton` when a glyph alone carries the action — navigation bars, toolbars, list-row accessories.

```jsx
<IconButton size="M" variant="fill"><Icon name="IconSettingMonoSettingWheel" size={20} /></IconButton>
```

Careful: TDS names these inversely — `size="L"` is the 32px box, `size="S"` is the 48px box. Radii 11 / 13 / 16.
