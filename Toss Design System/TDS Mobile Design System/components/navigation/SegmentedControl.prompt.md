Use `SegmentedControl` to filter the same list two to four ways. For more options, or for navigation between different views, use `Tab`.

```jsx
<SegmentedControl items={['일', '주', '월']} value={i} onChange={setI} />
```

Track radius 14, selected pill radius 10 with `--tds-shadow-tiny` — the shallowest shadow in the system.
