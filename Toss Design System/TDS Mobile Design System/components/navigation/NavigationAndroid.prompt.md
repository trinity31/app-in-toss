Use `NavigationAndroid` on Android screens instead of `Navigation`.

```jsx
<NavigationAndroid title="적금 계산기" logoSrc="assets/images/service-logo.png" />
```

The bar is the same Apps-in-Toss design on both platforms — the only differences the source defines are the height (54 vs 44), the back button box (48×48 vs 44×44), the back glyph (`icon-arrow-back-android-mono` vs the iOS chevron) and the title cap (168 vs 176). Do not substitute a Material top app bar.
