# 심화 타로 개선 실행 결과

2026-11-10. 사용자 지시에 따라 사례 검증은 대표 3개로 축소했다. 원안의 대규모 실험·사람 20쌍 검토·운영 전환은 이번 실행 범위에서 제외한다.

## 구현 완료

- [x] 내부 GPT 판단과 Gemini 사용자용 질문·요약 작성을 분리했다.
- [x] 본 풀이의 Terra 내부 근거 분석을 로컬에서 활성화했다.
- [x] 질문·본 풀이·확인 카드의 사용자 문장은 기존 Gemini로 고정했다. Gemini 오류 시 GPT 답변으로 대체하지 않는다.
- [x] 확인 카드에는 추가 GPT 분석을 적용하지 않는다. 최소 비교에서 이득이 확인되지 않았기 때문이다.
- [x] 카드별 허용 근거를 명시하고, 근거·카드 오류에 한해 같은 카드·자료로 Gemini가 1회만 교정한다.
- [x] 새 상담에 내부 처리 구성을 기록하고 공개 응답에서 내부 정보를 숨긴다. 기존 완료 답변은 재생성하지 않는다.
- [x] Jev 오프라인 비교 도구, 모델명 없는 채점, 본 풀이/확인 카드 평가 구분, 오류의 미채점 처리 및 비용 기록을 구현했다.
- [x] LangSmith에서 GPT 내부 판단·본 풀이 분석과 Gemini 작성을 구분해 기록한다.
- [x] 로컬 타로 인증과 임시 SQLite를 연결했다. 실제 구매·무료분 원장을 조작하지 않고 결제 없이 테스트한다.
- [x] 결과 화면에서 핵심 답변을 카드 상세보다 먼저 보여주고 처리 단계에 맞는 대기 안내를 제공한다.

- [x] 프런트엔드 타로·보관함·복구·로컬 인증 경계 검사 **43개 통과**.

- 현재 로컬: `http://127.0.0.1:5190/tarot?mode=deep`.
- 운영 기본값: 기존 Gemini 단독. 실제 운영 환경변수·DB 마이그레이션·배포는 변경하지 않았다.
