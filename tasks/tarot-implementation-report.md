## 최종 구성

1. GPT-6 Luna: 내부 질문 목적·정보 부족·배열 판단. 사용자 문장을 직접 전달하지 않는다.
2. Gemini 3.1 Flash Lite: 사용자용 질문·선택지·상담 요약 작성.
3. GPT-6.1 Terra: 본 풀이의 카드 근거와 질문의 연결, 충돌·미확인 사항에 대한 내부 분석.
4. Gemini 3.1 Flash Lite: 사용자에게 전달할 본 풀이·카드별 설명·종합·행동 조언 작성.
5. 확인 카드: Gemini 단독. 추가 GPT 분석의 비용·지연 대비 개선이 확인되지 않아 제외했다.
6. Jev: 명시적으로 실행하는 오프라인 품질 평가만 담당한다. 사용자 요청 경로에는 붙이지 않는다.

공개 답변 작성기를 GPT로 바꾸는 환경변수는 허용하지 않는다. Gemini 오류가 나도 GPT 원문을 대체 답변으로 내보내지 않는다. GPT 내부 조건은 원문에서 확인하며, 카드·자리·근거 검증은 서버에서 유지한다.

## 최소 사례 결과

사례는 현재 마음 탐색, 과거 사건 뒤 관계 회복, 두 대안 비교 3개다. 수정 후 동일 카드·자리·근거에서 구성별 한 번씩, 총 9개 레코드를 비교했다. 기준선도 동일한 공통 Gemini 작성 지침을 사용하므로 과거 운영 프롬프트의 역사적 성능과 직접 비교한 결과는 아니다.

| 내부 구성 | 본 풀이 Jev 평균 /100 | 측정한 전체 생성시간 평균 | 생성·Jev 추정 비용 합계 |
|---|---:|---:|---:|
| Gemini 단독 | 85.16 | 7.93초 | US$0.011267 |
| Luna 판단 + Gemini | 84.62 | 10.43초 | US$0.010590 |
| Luna 판단 + Terra 분석 + Gemini | 88.14 | 17.49초 | US$0.022764 |

시간에는 계획과 본 풀이, 관계 회복 사례의 확인 카드가 포함된다. 당시 Terra 구성은 확인 카드의 추가 GPT 분석도 포함했으나 최종 구현에서는 제외했다. 이 평균은 현재 모든 상담의 지연이나 p95를 보장하지 않는다. 비용은 토큰·표준 단가 추정이며 캐시 할인 등을 반영한 실제 청구액과 다를 수 있다. 수정 전 실패·재확인·브라우저 비용은 이 9개 합계와 별도다.

**해석의 한계:** 합성 3건·단일 실행이며 사람 블라인드 보정을 하지 않았다. +2.98점은 원안의 +5점 목표에 미달한다. 통계적 우위·실제 사용자 선호·모든 고민 유형의 개선을 주장하지 않으며 운영 자동 전환 근거로 사용하지 않는다.

## 발견한 문제와 처리

- 수정 전 관계 회복 2개 실행에서 카드 14의 설명에 카드 16의 근거 ID가 섞여 서버 검증이 실패했다. 실패 기록을 숨기지 않고 보존했다. 카드별 허용 근거를 명시하고, 같은 카드·자료로 Gemini가 1회 교정하도록 검사했다. 그래도 잘못되면 기존 오류·재시도 흐름을 유지한다.
- 확인 카드에서는 사용자 내면·과거를 추측하는 표현과 평가 대상 범위 혼동을 발견했다. Gemini 지침을 보완하고 Jev가 전체 질문 대신 대상 자리의 보충 의미를 평가하도록 수정했다. 원래 점수와 수정 평가 점수는 평가 버전이 달라 섞어 평균내지 않는다.
- 추가 GPT 확인 카드 분석은 비교 이득이 없어서 최종 경로에서 제거했다. 확인 카드는 Gemini가 직접 작성하고, 카드·근거 오류에 한해 같은 조건의 1회 교정만 허용한다.
- Jev의 Noul 값은 보정된 오류 확률로 해석하지 않으며, 운영 응답을 자동 차단하는 임계값으로 쓰지 않는다.

확인 카드의 최종 Gemini 단독 경로도 같은 저장 사례로 확인했다. GPT 호출 없이 완료됐지만 자동점수는 68.15/100이며, 문장 품질의 개선은 확인하지 못했다. 이 결과를 숨기지 않고 `clarifier-final-gemini-only.json`에 보존한다. 본 풀이 점수 상승을 확인 카드까지 일반화하지 않으며 운영 전환은 보류한다.
