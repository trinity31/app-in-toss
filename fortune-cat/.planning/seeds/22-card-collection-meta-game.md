# 22장 카드 컬렉션 메타게임

## 아이디어 (한 줄)
사용자가 메이저 아르카나 22장을 daily one-card 로 모으면 보상을 주는 컬렉션·완성 메타게임.

## 사용자 가치
- **장기 retention 후크:** daily lock 만으로는 매일 1번 들어오는 단기 후크 → 컬렉션이 "이번 주에 몇 장 모았지?" 라는 3주 단위 장기 후크 추가
- **4050 여성 친화:** 수집·완성 욕구는 광범위 인구 통계에 효과적
- **운명·우연 강화:** "오늘은 어떤 카드가 처음 나올까?" — 타로의 우연성 + 컬렉션의 호기심
- **22일 ≈ 3주 자연 retention 구간** — v1.1 milestone goal "재방문·체류" 와 직접 일치

## 보상 후보 (cross-sell with v1.0 자산)
1. **부적 무료 1회 쿠폰** — 22/22 완성 사용자에게. 기존 v1.0 IAP 흐름 재활용 → 전환율 측정 가능.
2. **딥리딩 1회 무료** — v1.0 신년운세 딥리딩 결제 자산 활용.
3. **LLM 고민상담 1회 무료** — 향후 v1.2+ 의 LLM 기능 출시 시 "수집자 우대" 로 활성 사용자 식별.
4. **시각 보상** — 22/22 완성 시 특별 카드 배경, 진행률 뱃지 (5/22, 10/22, 22/22 마일스톤).

## 구현 영향 범위 (대략)
- **데이터:** Toss Storage (또는 Supabase) `collected_cards: card_id[]` 추가. Phase 4 가 도입한 `todayDraw` 위에 매일 union 으로 누적.
- **UI:** 기록 탭(프로토타입의 archive 라우트 참고) — 22장 그리드, 미수집은 카드 뒷면 silhouette, 수집은 앞면.
- **로직:** 22/22 완성 트리거 + 보상 발급 + 중복/만료 처리.
- **분석:** "수집 진행률 X→Y 도달" 이벤트 (재방문 motivation 측정).

## 결정 보류 사항 (v1.2 시점 재검토)
- 보상 정책: 부적 쿠폰 vs 딥리딩 vs LLM 무료 — 시장 반응 데이터 보고 결정
- 22/22 완성 후 UX: "다시 처음부터" 옵션 제공 여부
- 같은 카드 중복 노출 정책: 그날 처음 카드면 컬렉션 카운트, 이미 수집한 카드도 노출 가능?

## v1.1 에 포함시키지 않은 이유
1. 컬렉션 UI(기록 탭 진행률 시각화 + 22/22 보상 트리거) 자체로 1~2 phase 분량 — daily lock 출시 일정 지연
2. 보상 정책(쿠폰 발급·만료·중복 사용 처리) 결정 사항 다수 — 별도 기획 필요
3. v1.1 = 깨끗한 daily 경험으로 시장 반응 받고, v1.2 가 메타게임 layer 로 retention 강화하는 흐름이 stage gating 관점에서 안전
