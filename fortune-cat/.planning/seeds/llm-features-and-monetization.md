# LLM 기능 도입 + 수익화 모델 전환

## 아이디어 (한 줄)
v1.1 의 daily one-card 가 정착하면, 다음 마일스톤에서 **LLM 기반 고민상담** + **3-card 스프레드** 를 추가하고, 이때 **LLM 비용 발생 시점에 맞춰 수익화** 도입.

## 배경
- v1.1 = daily one-card 무료 (Supabase 정적 텍스트 + 이미지 — 한계 비용 0)
- LLM 기능 추가 시: API 비용 발생 → 무한 무료 불가 → 수익화 필요
- 사용자가 v1.1 로 정착한 후 LLM 기능을 "프리미엄 가치" 로 제공하면 결제 동기 명확

## 후보 LLM 기능
1. **고민상담 (1:1 자유형)** — 사용자가 텍스트로 고민 입력 → LLM 이 카드 1장 + 맥락 답변
2. **3-card 스프레드** — 과거·현재·미래 / 마음·행동·결과 패턴. LLM 이 3장 조합 해석.
3. **카드 깊은 풀이** — 오늘의 카드에 사용자 상황 추가 입력 → 개인화 풀이 (현재는 정적 메시지)

## 수익화 패턴 후보
| 모델 | 설명 | 장점 | 단점 |
|------|------|------|------|
| 인앱결제 1회 | 고민상담 1회 = N원 | 결제 흐름 단순 (v1.0 부적 인프라 재활용) | 진입 장벽 |
| 인앱결제 회차권 | 3회 / 10회 묶음 | 단가 낮춤 | 미사용 회차 처리 |
| 광고 시청 후 1회 | LLM 호출 비용을 광고로 충당 | 무료 진입 | 광고 단가 vs LLM 단가 균형 필요 |
| 구독 (월정액) | 무제한 LLM | 예측 가능 매출 | 4050 사용자 수용도 미지수 |
| 22/22 컬렉션 보상 | 컬렉션 완성자에게 1회 무료 | 활성 사용자 식별 | 단독 수익원 안 됨 |
