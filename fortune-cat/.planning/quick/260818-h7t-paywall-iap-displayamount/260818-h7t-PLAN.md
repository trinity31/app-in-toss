<objective>
심화풀이 paywall의 가격 표기 "990원"과 백엔드 grant의 `amount: 990` 하드코딩을 제거하고,
토스 `IAP.getProductItemList()`가 내려주는 콘솔 등록값(`displayAmount`)을 단일 출처로 삼는다.
이 수정을 먼저 배포한 뒤 콘솔에서 가격을 변경하면, 앱 재배포 없이 가격이 반영된다.

Purpose: 가격 변경 시마다 앱 재배포·심사를 반복하지 않도록 가격 출처를 콘솔로 일원화.
Output: 부적 결제(AmuletPayment.jsx)와 동일한 IAP 상품 조회 패턴을 심화풀이에도 적용.
</objective>

<context>
- SDK 2.4.5의 `IapProductListItem`은 `sku / displayAmount / displayName / iconUrl / description / type`만
  제공한다. **숫자 금액 필드는 없다** → grant에 보낼 숫자는 `displayAmount`("1,200원")에서 파싱해야 한다.
- 부적(`AmuletPayment.jsx:80-105`)은 이미 `getProductItemList()` → SKU 매칭 → `displayAmount` 표시
  패턴을 쓰고 있어 가격 표기가 콘솔 값에 자동 연동된다. 심화풀이만 하드코딩 상태.
- 가격 하드코딩 위치: `DeepReadingResult.jsx:971, 1013, 1034` (UI 문구), `deepReadingPurchase.js:106` (`amount: 990`).
- 개발 브라우저 / 구버전 토스앱에서는 IAP가 `undefined`를 반환한다 → graceful degradation 필수
  (프로젝트 규약: 결제 외 흐름을 IAP 실패가 막지 않는다).
- 사용자 결정: grant `amount`는 `displayAmount` 파싱값을 보내고, 파싱 실패 시 990 폴백.
</context>
