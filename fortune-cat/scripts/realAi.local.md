# 로컬 브라우저에서 실제 AI 풀이

Node.js 24 이상과 기존 `node_modules`, `../../catbot/catbot-backend/venv` 및 백엔드 `.env`가 필요합니다.

```sh
cd /Users/trinity/Projects/app-in-toss/fortune-cat
nvm use
npm run dev:real-ai
```

http://127.0.0.1:5190/ 에서 확인합니다. 기존 백엔드를 수정하거나 종료하지 않고, 실제 백엔드 코드를 127.0.0.1:8020에 별도로 실행합니다. 5190·8020 포트가 비어 있어야 합니다. Ctrl-C로 두 서버를 종료합니다.

토스 브라우저 인증을 로컬 테스트 계정으로 대체합니다. 실제 모델·프롬프트·사주 계산·이용량 제한을 사용하므로 AI 사용료가 발생합니다. 사주 테스트 기록은 기존 백엔드 저장소에 저장되고, 타로 상담은 별도 임시 SQLite에만 저장합니다. 실행마다 새 테스트 계정이 만들어집니다. 별도로 실행한 백엔드 프로세스에서만 결제 화면을 건너뛰어 전체 풀이를 표시합니다. 타로도 결제 없이 여러 번 테스트할 수 있으며 결제 원장이나 가짜 구매 내역은 만들지 않습니다. 실제 결제·실제 토스 로그인은 이 모드에서 지원하지 않습니다.

심화 타로는 `http://127.0.0.1:5190/tarot?mode=deep`에서 확인합니다. 내부 질문 판단은 GPT-6 Luna, 본 풀이의 내부 근거 분석은 GPT-6.1 Terra이며, 사용자에게 보이는 질문·요약·최종 답변은 모두 Gemini 3.1 Flash Lite입니다. 확인 카드는 Gemini 단독으로 작성합니다. 새 로컬 상담에만 이 구성을 적용하며 운영 기본값은 변경하지 않습니다. 로컬 서버 종료 시 타로 임시 기록은 삭제됩니다.

서버용 인증키는 실행 시 메모리에 새로 생성하고 브라우저에 전달하지 않습니다. 브라우저의 사용자 ID는 서버에서 테스트 계정 ID로 덮어씁니다. 로컬 전용 연결 코드는 앱 빌드에서 import하지 않습니다. 이 별도 백엔드의 Slack 알림은 비활성화합니다. LangSmith 추적은 활성화하며, 백엔드 `.env`의 기존 인증키·프로젝트 설정을 사용합니다(프로젝트 미설정 시 `default`). 테스트 입력과 AI 응답도 해당 프로젝트의 추적 기록에 포함됩니다. 캐시에서 반환한 풀이는 새 모델 호출 기록을 만들지 않습니다.

`npm run preview:local`의 5189 화면은 여전히 AI 호출 없는 합성 데이터 미리보기입니다.

인증 경계 검사: `node --test scripts/realAiProxy.local.test.mjs`.

실제 AI 브라우저 검사(풀이 1건 과금): `node scripts/realAi.browser.mjs --live`. Playwright 모듈 경로를 `PLAYWRIGHT_MODULE`로 지정할 수 있습니다.

실제 타로 브라우저 검사(상담 1건 과금): `node scripts/tarotRealAi.browser.mjs --live`. 내부 GPT 단계와 Gemini 작성은 LangSmith에 기록됩니다. Jev는 백엔드의 오프라인 비교 도구에서만 호출하며 사용자 요청에는 붙이지 않습니다.
