# 실제 앱 화면으로 로컬 확인

```sh
cd /Users/trinity/Projects/app-in-toss/fortune-cat
npm run preview:local
```

**http://127.0.0.1:5189** 에서 실제 `src/main.jsx → App.jsx`와 홈·서비스 소개·입력·로딩·풀이 결과·보관함·타로 화면을 확인합니다. 별도의 고객 선택/테스트 제어 화면은 없습니다. 종료는 **Ctrl-C**입니다. Node24+, 기존 node_modules/백엔드 venv가 필요하며 5189·8019 포트는 비어 있어야 합니다.

화면 코드는 실제 앱과 동일합니다. 브라우저에 없는 토스 브리지와 외부 서비스만 로컬 어댑터로 대체합니다. 메뉴는 저장소의 기존 메뉴 코드·직업 메뉴와 로컬 카탈로그, 데일리 타로는 저장소의 실제22장 seed/카드 이미지를 사용합니다. 운영 DB의 최신 메뉴 목록과 동일하다고 보장하지 않습니다. 풀이/보관함 내용·이용권·결제는 합성 데이터입니다. 실제 토스 사용자·OAuth·mTLS 연결 검증은 기기에서 별도로 필요합니다.

홈에서 사주 메뉴를 누르고 처음에 `시작하기`를 누르면 로그인 동의 없이 실제 정보 입력 화면으로 갑니다. 임의의 테스트 정보를 입력해 결과를 보고, 보유 이용권으로 전체 풀이를 열고, 보관함과 타로 탭을 확인할 수 있습니다. 새로고침/재진입은 새 익명 증명을 발급하며 소개 완료 표시만 로컬에 남깁니다. 토큰은 메모리에만 유지합니다. 실제 고객 기록을 조회하지 않습니다.

프런트엔드를 임시 폴더로 복사해 `.env` 없이 실행합니다. Supabase·Firebase·Sentry·광고·공유/결제 SDK는 외부 연결이 없는 로컬 모듈로 대체하며, 카드 이미지도 로컬 파일을 사용합니다. CSP와 네트워크 가드가 외부 요청을 차단합니다. 백엔드도 실제 인증·소유권 코드를 사용하되, 공급자·데이터·AI·결제는 격리된 합성 어댑터입니다. 운영 SQL·배포·키 변경은 수행하지 않습니다. 이 어댑터들은 운영 앱/AIT에서 import하지 않습니다.

자동 화면 검사: Playwright 설치 경로를 지정한 뒤 `node scripts/actualApp.browser.mjs`. 기존 세부 실패/고객별 합성 테스트 도구는 `npm run test:anonymous-session:local`로 별도 유지합니다.
